PENDIENTE DE INTEGRACIÓN EXTERNA
El proyecto entregado no incluye el código ni la URL del microservicio Spring Boot del equipo.
Por eso se conserva el consumo Retrofit de la API pública JSONPlaceholder y se documenta
cómo conectar el backend real cuando se conozca su URL y contrato (endpoints/JSON).
Tampoco se puede generar una APK release firmada sin que el equipo cree su propio keystore.
