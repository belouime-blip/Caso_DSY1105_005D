APP API REST - GUIA 14

Como abrir:
1. Descarga y descomprime AppApiRest_Grupo1.zip.
2. Abre Android Studio.
3. Selecciona File > Open y elige la carpeta AppApiRest_Grupo1 (la que contiene settings.gradle.kts).
4. Acepta la sincronización de Gradle y espera a que descargue dependencias.
5. Selecciona un emulador en Device Manager y pulsa Run.

Paquete: com.example.apirest
API: https://jsonplaceholder.typicode.com/posts

Incluye:
- Modelo Post
- ApiService con GET, POST, PUT y DELETE
- RetrofitInstance
- PostRepository
- PostViewModel
- PostScreen con Jetpack Compose
- MainActivity
- Permiso INTERNET

IMPORTANTE:
El proyecto incluye el código fuente, pero no incluye gradle-wrapper.jar ni un emulador.
Android Studio debe tener conexión a Internet para descargar Gradle y las dependencias.
JSONPlaceholder es una API de prueba: POST/PUT/DELETE simulan operaciones y no guardan cambios permanentes.

Para completar lo colaborativo de la guía:
- Crear repositorio privado en GitHub y agregar compañero/docente.
- Crear tablero Trello con listas Por hacer, En curso y Finalizado.
- Tomar capturas reales de la app ejecutándose y subirlas al repositorio.
